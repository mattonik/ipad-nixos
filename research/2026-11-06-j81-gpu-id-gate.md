# J81 GPU identity probe gate

Date: 2026-11-06

With the guarded PMGR consumer holding the GFX domain active, the staged
read-only identity probe ran through its first two checkpoints:

```
stage=after-pmgr-read raw=0x000003ff target=15 actual=15 auto=0 reset=0
stage=after-gpc-state raw=0x00000000
stage=finished rc=1
```

The probe stopped at that point because the GPC state was not the required
settled value `1`. It did not read the GPC control register or either GPU ID
register. The private transcript is stored at
`artifacts/live/private/gpu-observations/2026-11-06-gpu-id-test-01.log`.

The PMGR lease remained healthy after the stop (`runtime_status=active`,
`runtime_usage=1`), and the Linux shell stayed responsive. This distinguishes
the result from a bus hang: the GFX power domain reached PMGR state 15, but
the GPC did not report the expected ready state. Do not retry the probe in
this boot; the one-shot guard intentionally treats this as a stop condition.

## Result

- PMGR domain acquisition: **pass**.
- GPC state read: **safe, value `0`**.
- GPC control/GPU revision/core-ID reads: **not attempted**.
- Firmware, bridge writes, and rendering: **not attempted**.
