[Inference] Strongest cheap rail discriminator: compare retained pre/post-GPC PMIC bytes 0/2 for 0128, DWI PS and +2300c from *one page-5-high Linux boot*, preferably archived read-only controls with no core load. A same-phase successful iPadOS PMIC read via a supported diagnostic would test whether the downstream code matches. A PMIC transaction requires a functioning driver and cannot be obtained from a simple MMIO observer of PMGR words. No attributed pre-hook I2C/SMC/SEP voltage transaction from stock code or verified direct PMIC write value is established. Correlation with GPC is consistent with automatic voltage-manager/DWI hardware delivery.
