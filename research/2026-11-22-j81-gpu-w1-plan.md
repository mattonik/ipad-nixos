# W1 and W2a: first GPU register writes (plan, 2026-11-22)

From `2026-11-22-j81-meta-boot-research-result.md` (steps W1, W2) and the R1 result (META_BOOT 0, SOFT_RESET 0). Module sha256 de0c7357....

**W1** (the requested test): rewrite META_BOOT (0xbf8, low word) with the value just read (expected 0) and read it back. Only shows that a direct RGX store does not fault; same value, so it cannot show the store changed anything.
**W2a** (the informative one, run second in the same boot): stock's first SOFT_RESET staging write. 64-bit store 0x00e7fffffffffc1d to SOFT_RESET (0x100) (expected old value 0), read it back, then store 0, read back, then re-read CORE_REVISION. Interrupts off for the window; only SOFT_RESET is read while blocks are in reset. Stock does the same writes on J81 but, if its global "use Fender" bit is set (J81 default per the research), through a Fender mailbox. Interpretation: readback equals the value written = direct stores land; readback 0 or other = they do not (Fender mailbox needed); a hang = the store faulted or blocks in reset are not readable. W2a puts most GPU blocks into reset for a few microseconds (which stock does too) and then releases them.
Prediction: W1 reads 0 back. W2a: unknown; the research expects stock to need the Fender path only if the bit is set; a direct store reading back the value would be good news.
Order of the run: identity (as always), then write-w1, write-w2a. No survey reads. Dashboard stopped.
A hang: watchdog reset after 20 s, fresh DFU; the log shows the last announced stage.
